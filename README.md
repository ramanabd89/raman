# Raman Mobile — متجر موبايلات وإكسسوارات

متجر إلكتروني كامل (Frontend + Backend) باللغات: **کوردی (سۆرانی)، العربية، English**، مع دعم الكتابة من اليمين لليسار وتصميم مناسب للموبايل.

## المميزات

**واجهة الزبون**
- الصفحة الرئيسية: شريط الأقسام، بانرات متحركة، تخفيضات سريعة مع عدّاد وقت، وترتيب المنتجات (لك / الأكثر مبيعاً / الأرخص / الأغلى)
- بطاقات المنتجات عليها شارات: نسبة الخصم، مميز، رائج، عدد المبيعات، كمية قليلة، نفذت الكمية
- بحث مع كلمات رائجة، وقائمة أقسام فيها أقسام فرعية، وقائمة جانبية لتبديل اللغة وروابط التواصل
- صفحة المنتج مع معرض صور ومنتجات مشابهة
- سلة تسوق مع شريط تقدم للتوصيل المجاني، وإتمام الطلب بالدفع عند الاستلام
- تسجيل دخول وحساب جديد برقم الموبايل وكلمة مرور
- الملف الشخصي: مجموع المشتريات، رصيد المحفظة، كود الدعوة مع مشاركة واتساب، حالات الطلبات، العناوين، تعديل البيانات، التواصل مع الدعم
- طلباتي: فلترة حسب الحالة، تتبع الطلب، وإلغاء الطلب وهو قيد الانتظار

**لوحة التحكم** (`/admin`)
- إحصائيات: المبيعات، الطلبات، المخزون القليل، الأكثر مبيعاً
- إدارة الطلبات وتغيير حالتها: قيد الانتظار ← قيد التجهيز ← في الطريق ← تم التوصيل / ملغي
- إضافة وتعديل المنتجات مع رفع الصور (3 لغات)، وأقسام رئيسية وفرعية، وبانرات
- الزبائن: تعديل رصيد المحفظة ومنح صلاحية المدير
- الإعدادات: اسم المتجر، أجور التوصيل، حد التوصيل المجاني، مكافأة الدعوة، موعد نهاية التخفيضات، المدن، روابط التواصل

**نظام الدعوة:** لما يسجّل صديق بكود دعوتك ويوصله أول طلب، يضاف مبلغ المكافأة إلى محفظتك. الزبون يقدر يستخدم رصيد المحفظة عند الدفع.

## التشغيل

يحتاج Node.js 22.13 أو أحدث (قاعدة البيانات SQLite مدمجة في Node، ما تحتاج تثبيت شي إضافي).

```bash
npm install
npm start
```

- المتجر: http://localhost:3000
- لوحة التحكم: http://localhost:3000/admin

**حساب المدير الافتراضي:** `07500000000` / `admin123`
⚠️ غيّر كلمة المرور فوراً (من الملف الشخصي ← تغيير الرقم والاسم)، أو حدّد الحساب قبل أول تشغيل:

```bash
ADMIN_PHONE=07701234567 ADMIN_PASSWORD='كلمة-سر-قوية' npm start
```

أول تشغيل يضيف منتجات وأقسام تجريبية. احذفها أو عدّلها من لوحة التحكم.

## متغيرات البيئة

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `PORT` | `3000` | منفذ السيرفر |
| `DATA_DIR` | `./data` | مكان ملف قاعدة البيانات |
| `UPLOAD_DIR` | `./uploads` | مكان الصور المرفوعة |
| `ADMIN_PHONE` / `ADMIN_PASSWORD` | — | حساب المدير عند أول تشغيل |

## الهيكل

```
server/index.js    ← الـ API (Express): المنتجات، الطلبات، الحسابات، لوحة التحكم
server/db.js       ← قاعدة البيانات SQLite + البيانات التجريبية
public/index.html  ← واجهة المتجر
public/js/app.js   ← منطق الواجهة (Vanilla JS بدون build)
public/js/i18n.js  ← الترجمات (کوردی / عربي / English)
public/css/style.css
public/admin/      ← لوحة التحكم
```

## النشر

يشتغل على أي VPS أو منصة تدعم Node.js (مثل Railway وRender وFly.io). احفظ مجلدي `data/` و`uploads/` على قرص دائم (persistent volume) عشان ما تضيع البيانات والصور.
