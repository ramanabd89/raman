# RamanPhone — متجر موبايلات وإكسسوارات (PHP 8.1+ · MySQL · Vanilla JS)

متجر كامل بثلاث لغات (**کوردی، العربية، English**)، مكتوب بـ **PHP صافي بنظام MVC** — بدون Composer، بدون أطر عمل، وبدون Node.js.
يشتغل على أي استضافة PHP عادية (Hostinger، cPanel…) بالدومين الرئيسي أو داخل مجلد فرعي.

## التنصيب (5 دقائق)

1. ارفع كل الملفات إلى `public_html` (أو مجلد فرعي مثل `public_html/shop`).
2. من لوحة الاستضافة أنشئ قاعدة بيانات MySQL ومستخدم لها.
3. افتح `https://دومينك/install.php`:
   - يفحص المتطلبات (PHP 8.1+، PDO MySQL، mbstring، curl، صلاحية الكتابة على `uploads/` و`storage/`).
   - اكتب بيانات القاعدة، رقم وكلمة مرور المدير، واسم المتجر واللغة الافتراضية.
   - يُنشئ الجداول، يكتب `config.php`، ويعطيك **رابط لوحة تحكم سري** (مثل `/panel-a8k2m9x`) — احفظه.
4. اضغط **«حذف ملف التنصيب»** بنهاية التنصيب (الملف يقفل نفسه حتى لو ما حذفته).
5. ادخل اللوحة ← **الإعدادات**: حط مفتاح OTPIQ واضغط «إرسال رسالة تجربة»، وفعّل تيليجرام واضغط «إرسال رسالة تجربة».

> وضع التجربة لرسائل التحقق (`otp_test_mode`) يُظهر الرمز على الشاشة. أطفئه قبل الافتتاح.

## التركيب

```
index.php            نقطة الدخول الوحيدة (كل الطلبات تمر من هنا عبر .htaccess)
install.php          المثبّت (3 لغات)
app/Config           الإعدادات والاتصال بالقاعدة
app/Core             Router · Request · Response · Auth · Csrf · Lang · View · Validator · RateLimiter · SqlRunner …
app/Middleware       Auth · StaffRbac · Csrf · Maintenance · RateLimit
app/Models           Product · Order · Repair · TradeIn · Coupon · Setting · Wishlist · StockMovement …
app/Controllers      واجهات الزبون + Admin/ + SeoController (صفحات SSR، sitemap، robots، الطباعة)
app/Services         Otpiq · Telegram · ImageUpload · Totp · Backup · Search · Seo · HttpClient
app/Views            قوالب PHP (المتجر، الأخطاء، الطباعة A4/80mm، شهادة الضمان، اللوحة)
lang/{ku,ar,en}.php  نصوص السيرفر  —  js/i18n.js و admin/i18n.js نصوص الواجهات
database/            schema.sql و seed.sql
storage/backups      النسخ الاحتياطية اليومية (محمي من الوصول)
uploads/             الصور المرفوعة (ممنوع تشغيل أي سكربت فيه)
```

## أهم المميزات

- **روابط SEO بكل لغة:** `/ku/…` `/ar/…` `/en/…`، صفحات منتجات وأقسام بأسماء مقروءة، `/p/12` يحوّل 301 للرابط الصحيح، canonical و hreflang و Open Graph و JSON-LD (متجر، منتج وسعر وتقييم، أسئلة، مسار التصفح)، `sitemap.xml` و `robots.txt`.
- **الأسعار بالدينار فقط** للزبون (مساعد الدولار للمدير فقط).
- **رمز التحقق عبر OTPIQ** مع حماية: رمز عشوائي، تخزين مشفّر، 5 دقائق صلاحية، 5 محاولات، 60 ثانية بين الإرسال، وحدود لكل IP ولكل رقم.
- **تيليجرام:** طلبات جديدة، طلبات بقيمة عالية، إلغاء، تصليح، مخزون قليل — تختار اللغة والأحداث من الإعدادات.
- واجهة موبايل من عرض 320px: شريط سفلي، زر شراء ثابت، قوائم منبثقة، PWA (`manifest.json`).
- فلترة بالماركة والسعة والرام والسعر، مقارنة، مفضلة، آخر المشاهدات، تخفيضات بعداد، بكجات إكسسوارات متوافقة بخصم، تقييمات، مناطق توصيل، كوبونات، محفظة وكاش باك، دعوة، روابط حملات، دفع عند الاستلام وواتساب.
- **التصليح:** قائمة أسعار، نصيحة صادقة، مواعيد بتوقيت بغداد، تحديد الموقع على الخريطة، تتبع، موافقة على الكلفة الإضافية، صور، تعليقات، ضمان بالـIMEI وشهادة QR للطباعة وصفحة `/warranty`.
- **تبديل الأجهزة** و **ساعدني أختار موبايل**.
- **اللوحة:** صلاحيات للموظفين + تحقق بخطوتين، حركة مخزن، أنواع بـSKU، تنبيه مخزون، تغيير أسعار بالجملة، طلبات مع علامات احتيال، IMEI للأجهزة المباعة، طباعة A4 و80mm، سلات متروكة مع واتساب، أرباح شهرية ولفترة محددة، تحليل زوار، محتوى، سجل عمليات، نسخ احتياطي يومي ويدوي (SQL). اللوحة نفسها بثلاث لغات.
- **الأمان:** CSRF، كوكي HttpOnly + SameSite=Lax، `password_hash`، رفع صور مقيّد، رموز أخطاء صحيحة (401/403/404/405/422/429/503)، `noindex` على اللوحة والحساب والدفع والـAPI.
