# Raman Mobile — متجر موبايلات وإكسسوارات

متجر إلكتروني كامل (Frontend + Backend) باللغات: **کوردی (سۆرانی)، العربية، English**، مع دعم الكتابة من اليمين لليسار وتصميم مناسب للموبايل.

## المميزات

**واجهة الزبون**
- الصفحة الرئيسية: شريط الأقسام، بانرات متحركة، تخفيضات سريعة مع عدّاد وقت، وترتيب المنتجات (لك / الأكثر مبيعاً / الأرخص / الأغلى)
- بطاقات المنتجات عليها شارات: نسبة الخصم، مميز، رائج، عدد المبيعات، كمية قليلة، نفذت الكمية
- بحث مع كلمات رائجة، وقائمة أقسام فيها أقسام فرعية، وقائمة جانبية لتبديل اللغة وروابط التواصل
- صفحة المنتج مع معرض صور ومنتجات مشابهة
- سلة تسوق مع شريط تقدم للتوصيل المجاني، وإتمام الطلب بالدفع عند الاستلام
- تسجيل دخول وحساب جديد برقم الموبايل وكلمة مرور، مع **رمز تحقق (OTP) يوصل بالرسائل أو بالواتساب** عند التسجيل، واستعادة كلمة المرور، وتغيير الرقم
- الملف الشخصي: مجموع المشتريات، رصيد المحفظة، كود الدعوة مع مشاركة واتساب، حالات الطلبات، العناوين، تعديل البيانات، التواصل مع الدعم
- طلباتي: فلترة حسب الحالة، تتبع الطلب، وإلغاء الطلب وهو قيد الانتظار

**لوحة التحكم** (`/admin`)
- إحصائيات: المبيعات، الطلبات، المخزون القليل، الأكثر مبيعاً
- إدارة الطلبات وتغيير حالتها: قيد الانتظار ← قيد التجهيز ← في الطريق ← تم التوصيل / ملغي
- إضافة وتعديل المنتجات مع رفع الصور (3 لغات)، وأقسام رئيسية وفرعية، وبانرات
- الزبائن: تعديل رصيد المحفظة ومنح صلاحية المدير
- الإعدادات: اسم المتجر، أجور التوصيل، حد التوصيل المجاني، مكافأة الدعوة، موعد نهاية التخفيضات، المدن، روابط التواصل

**نظام الدعوة:** لما يسجّل صديق بكود دعوتك ويوصله أول طلب، يضاف مبلغ المكافأة إلى محفظتك. الزبون يقدر يستخدم رصيد المحفظة عند الدفع.

## التشغيل

يحتاج Node.js 22.13 أو أحدث (قاعدة البيانات SQLite مدمجة في Node، ما تحتاج تثبيت شي إضافي).

```bash
npm install
npm start
```

- المتجر: http://localhost:3000
- لوحة التحكم: http://localhost:3000/admin

**حساب المدير الافتراضي:** `07500000000` / `admin123`
⚠️ غيّر كلمة المرور فوراً (من الملف الشخصي ← تغيير الرقم والاسم)، أو حدّد الحساب قبل أول تشغيل:

```bash
ADMIN_PHONE=07701234567 ADMIN_PASSWORD='كلمة-سر-قوية' npm start
```

أول تشغيل يضيف منتجات وأقسام تجريبية. احذفها أو عدّلها من لوحة التحكم.

## رسائل التحقق (OTP)

عند التسجيل أو استعادة كلمة المرور أو تغيير الرقم، يوصل للزبون رمز من 6 أرقام:
- الرمز صالح **5 دقائق** ويُستخدم مرة وحدة بس، وبعد **5 محاولات خاطئة** يبطل.
- إعادة الإرسال بعد **60 ثانية**، وحد أقصى 5 رموز لكل رقم و20 رمز لكل IP بالساعة.
- الرموز تنحفظ في قاعدة البيانات مشفّرة (hash).

اختر طريقة الإرسال بالمتغير `SMS_PROVIDER`:

| القيمة | الوصف | المتغيرات المطلوبة |
|---|---|---|
| `console` (الافتراضي) | **للتجربة بس**: الرمز يُطبع في سجل السيرفر ويظهر على الشاشة | — |
| `twilio` | رسالة SMS عبر Twilio | `TWILIO_ACCOUNT_SID`، `TWILIO_AUTH_TOKEN`، و`TWILIO_FROM` أو `TWILIO_MESSAGING_SERVICE_SID` |
| `whatsapp` | واتساب عبر WhatsApp Cloud API من Meta | `WHATSAPP_TOKEN`، `WHATSAPP_PHONE_NUMBER_ID`، `WHATSAPP_TEMPLATE`، و`WHATSAPP_TEMPLATE_LANG` (الافتراضي `en`) |

مثال:
```bash
NODE_ENV=production SMS_PROVIDER=whatsapp WHATSAPP_TOKEN=... WHATSAPP_PHONE_NUMBER_ID=... WHATSAPP_TEMPLATE=otp_code npm start
```

- **واتساب:** لازم تسوي في Meta Business قالب (template) من نوع **Authentication** وينوافق عليه، وتحط اسمه في `WHATSAPP_TEMPLATE`.
- الأرقام المحلية مثل `0750xxxxxxx` تتحول تلقائياً إلى `+964750xxxxxxx`.
- إذا شغّلت الموقع بـ `NODE_ENV=production`، الرمز ما يظهر على الشاشة نهائياً.
- إذا السيرفر ورا Nginx أو منصة استضافة، ضيف `TRUST_PROXY=1` عشان حدود المحاولات تشوف IP الزبون الحقيقي.

## متغيرات البيئة

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `PORT` | `3000` | منفذ السيرفر |
| `DATA_DIR` | `./data` | مكان ملف قاعدة البيانات |
| `UPLOAD_DIR` | `./uploads` | مكان الصور المرفوعة |
| `ADMIN_PHONE` / `ADMIN_PASSWORD` | — | حساب المدير عند أول تشغيل |
| `PUBLIC_URL` | — | رابط الموقع (يظهر في إشعارات تيليجرام) |
| `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` | — | إشعارات الطلبات |
| `OTP_ALLOWED_PREFIXES` | `+964` | الدول المسموح إرسال الرموز لها |
| `BACKUP_KEEP` | `14` | عدد النسخ اليومية المحفوظة |
| `TRUST_PROXY` | — | `1` إذا السيرفر خلف Nginx/Caddy/منصة |

## الهيكل

```

```

## الشراء بدون كلمة مرور

- لما يضغط الزبون «إتمام الطلب» وهو مو مسجّل، يكتب **رقمه بس**، يوصله رمز، ولو كان جديد يكتب اسمه. بعدها يكمل الطلب مباشرة.
- الحساب ينسوّى تلقائياً. وإذا يريد كلمة مرور بعدين، يسوّيها من «نسيت كلمة المرور».
- **حسابات المدراء لازم تدخل بكلمة المرور** (مع التحقق بخطوتين)، والدخول بالرمز بس مقفول عليهم.

## أجور التوصيل حسب المدينة

من الإعدادات، «مناطق التوصيل»: تضيف كل مدينة وأجورها. الزبون يختار مدينته عند الطلب والأجور تنحسب تلقائياً، والسيرفر يرفض أي مدينة مو موجودة بالقائمة. التوصيل المجاني فوق مبلغ معين يبقى شغّال.

## الأسعار بالدولار

1. من الإعدادات حط **سعر صرف الدولار** (مثلاً 1480)، وحدد التقريب (لأقرب 250 أو 500 أو 1000 دينار).
2. بالمنتج فعّل **«السعر بالدولار»** واكتب السعر بالدولار، للمنتج أو لكل نوع.
3. لما يتغير سعر الصرف، تغيّر رقم واحد بالإعدادات و**كل الأسعار تتحدث** فوراً.

- لما تفعّل الخيار على منتج سعره بالدينار، الأرقام تتحول تلقائياً.
- السيرفر يرفض أي سعر دولار فوق 50,000$، حتى ما ينكتب مبلغ بالدينار بالغلط.
- السلة تجيب الأسعار الحالية من السيرفر، فالزبون ما يشوف سعر قديم.

## معاينة الروابط (واتساب، فيسبوك، تيليجرام)

بصفحة المنتج زر **«مشاركة»** يرسل رابط بالشكل `https://موقعك/p/12`. لما ينرسل بالواتساب يطلع **صورة المنتج واسمه وسعره**. الصفحة الرئيسية بعد إلها معاينة باسم المتجر.
> حط `PUBLIC_URL` برابط موقعك الحقيقي عشان روابط الصور تكون صحيحة.

## ضغط الصور

كل صورة ترفعها تتعدل تلقائياً:
- تتصغر لحد 1400px، وتتحول لـ **WebP** (عادة أصغر من الأصلية بحدود 5 إلى 10 مرات).
- تتعدل لو مقلوبة، وتنحذف منها **البيانات المخفية** مثل موقع التصوير (GPS).
- تنسوّى نسخة 1200×630 للمعاينة.
- الحد الأقصى للرفع 15MB، عشان صور الموبايل الكبيرة تنقبل.

## الحماية من الطلبات الوهمية

- **حد للطلبات المعلّقة:** كل زبون يقدر يكون عنده طلبين «قيد الانتظار» كحد أقصى (تتغير من الإعدادات).
- **حظر الزبون:** من صفحة «الزبائن»، الزبون المحظور ما يقدر يرسل طلبات.
- **تنبيه «اتصل للتأكيد»:** الطلبات فوق مبلغ معين (الافتراضي مليون دينار) تظهر بعلامة في لوحة التحكم وفي إشعار تيليجرام.
- **سجل الإلغاء:** جنب كل طلب يظهر كم طلب ملغي سابقاً لنفس الرقم.

## الأمان

- **التحقق بخطوتين للمدير:** من «الأمان والنسخ»، فعّله بتطبيق Google Authenticator أو Microsoft Authenticator.
- **مدة الجلسات:** جلسة الزبون تنتهي بعد 30 يوم، وجلسة المدير بعد 7 أيام.
- **حدود محاولات الدخول:** تنحفظ في قاعدة البيانات فتبقى حتى بعد إعادة التشغيل. 8 محاولات خاطئة لكل رقم و30 لكل IP خلال 15 دقيقة.
- **رموز التحقق:** تنرسل بس للأرقام العراقية (`OTP_ALLOWED_PREFIXES`، الافتراضي `+964`)، حماية من احتيال الرسائل.
- **الصور المرفوعة:** ينفحص محتوى الملف، مو بس نوعه المعلن.
- **سجل عمليات المدراء:** منو غيّر سعر، منو حظر زبون، منو غيّر الإعدادات.
- **لوحة التحكم تنبّهك** بالمشاكل قبل الافتتاح: كلمة المرور الافتراضية، التحقق بخطوتين غير مفعّل، الرسائل في وضع التجربة، تيليجرام غير مربوط.

## إشعارات الطلبات على تيليجرام

1. افتح تيليجرام وابحث عن **@BotFather**، اكتب `/newbot` واتبع الخطوات، وانسخ الـ **token**.
2. افتح البوت الجديد واضغط **Start**. (أو ضيفه لكروب فيه موظفينك.)
3. افتح `https://api.telegram.org/bot<TOKEN>/getUpdates` بالمتصفح، وانسخ رقم `chat.id`.
4. حط `TELEGRAM_BOT_TOKEN` و`TELEGRAM_CHAT_ID` في متغيرات البيئة. وحط `PUBLIC_URL` (رابط موقعك) عشان يظهر رابط اللوحة داخل الإشعار.

## النسخ الاحتياطي

- **نسخة تلقائية يومياً** في `data/backups`، وتبقى آخر 14 نسخة (`BACKUP_KEEP`).
- من «الأمان والنسخ» تقدر **تنزّل نسخة على جهازك**. سوّيها أسبوعياً على الأقل.
- **للاسترجاع:** وقّف السيرفر، بدّل `data/store.db` بالنسخة، وشغّل من جديد.

## النشر على سيرفر خاص (موصى به للبيع الحقيقي)

**1. استأجر VPS** فيه 1 إلى 2 GB رام، بحدود 5 إلى 7 دولار بالشهر، من Hetzner أو DigitalOcean أو Contabo. اختار **Ubuntu 24.04**.

**2. اشترِ دومين** (مثل `mystore.com`)، وفي إعدادات الـ DNS ضيف سجل **A** يأشّر على IP السيرفر.

**3. على السيرفر:**
```bash
curl -fsSL https://get.docker.com | sh
git clone https://github.com/ramanabd89/raman.git store && cd store
git checkout claude/fervent-johnson-j96kpi
cp .env.example .env && nano .env   # عبّي الدومين وكلمة سر المدير ومفاتيح واتساب وتيليجرام
docker compose up -d --build
```
Caddy يجيب شهادة **HTTPS مجانية** تلقائياً. والبيانات والصور تنحفظ في volume دائم، فما تضيع مع التحديثات.

**للتحديث لاحقاً:**
```bash
git pull && docker compose up -d --build
```

## Render (للتجربة فقط)

`render.yaml` يشغّل المتجر على الخطة المجانية، بس **البيانات تنمسح مع كل إعادة تشغيل**. إذا تريد تبقى على Render: ترقّى لخطة مدفوعة وضيف **Disk** على المسار `/var/data`، وحط `DATA_DIR=/var/data/db` و`UPLOAD_DIR=/var/data/uploads`.
